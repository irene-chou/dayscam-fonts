# DaysCam 字型下載點

DaysCam App 的「更多字型」從這裡下載開源字型。檔案是上游官方發行的**原檔**，未經修改，依各自授權轉散布。

| 字型 | 檔案 | 版本 | 來源 | 授權 |
|---|---|---|---|---|
| jf open 粉圓 | `huninn/jf-openhuninn-2.1.ttf` | 2.1 | https://github.com/justfont/open-huninn-font/releases/tag/v2.1 | SIL OFL 1.1（`huninn/LICENSE.txt`）；漢字部分衍生自 Kosugi Maru，Apache-2.0（`huninn/APACHE-LICENSE-2.0.txt`） |
| 芫荽 Iansui | `iansui/Iansui-Regular.ttf` | 1.020 | https://github.com/ButTaiwan/iansui/releases/tag/v1.020 | SIL OFL 1.1（`iansui/OFL.txt`） |
| 思源宋體 Noto Serif TC Bold | `noto-serif-tc/NotoSerifTC-Bold.otf` | 2.003（SubsetOTF） | https://github.com/notofonts/noto-cjk/tree/main/Serif/SubsetOTF/TC | SIL OFL 1.1（`noto-serif-tc/LICENSE.txt`） |

App 只讀固定 tag 的檔案，並比對大小與 SHA-256。更新字型時新增 tag，不覆寫舊 tag。
